# U3 生命周期验收记录

基线：`21cd072`。只使用合成源、隔离账号目录、模拟子进程和本地模拟在线服务；未读取真实聊天、密钥或用户档案，未运行真实密钥提取或请求真实在线转写 API。

## 已实施

任务固定账号和对象。停止申请进入正在停止状态；分块复制、摘要、解密页面及 WAL、历史会话逐库和导入批次在安全边界检查。通讯录与相关快照指针一次提交，导入在提交前取消时回滚消息、元数据、基准和设置；提交开始后等实际结果。语音逐条发布；当前条识别完成前收到停止请求时不覆盖已有成功结果。在线请求发出后等待返回或超时，再停止。

Windows 启动的密钥工具、语音 worker 及其下游进程由 Job Object 管理；停止和超时等待进程组退出。未发布资源清理失败时保留路径与失败状态，阻止新维护、切号和退出，可在任务面板重试清理。重启将运行或正在停止的任务标为中断，已发布档案保留，可按原范围手动重试。永久清理、空间回收及原生导出保存仍保护退出。

## 隔离验证

`D:/efficiency/anaconda3/envs/pytorch/python.exe scripts/verify_u3.py` 在导入 `web.app` 之前设置临时数据根目录；130 项通过，0 失败、0 错误、0 跳过。覆盖合成账号隔离、固定范围、重复取消、重启、导入批次和提交前后、失败回滚及重试、快照复制和解密页面、密钥模拟工具、语音成功结果复用、在线请求等待、worker 及下游进程退出、资源清理失败及重试、导出保存和关闭保护，以及 U1/U2 相关搜索、隐藏、清理、空间回收和加密 WAL 回归。模拟在线服务只监听本机地址。

实际 Chrome 界面使用 `tests/u3_fixture_server.py` 的合成数据：核对一个会话、开始导入、看到阶段进度，点击停止后看到“正在停止”，资源释放后看到“已取消”，重新执行时仍列原账号和会话，随后成功完成。

基础版实际 CMD 入口以中文空格路径和隔离数据启动，核对随包 `runtime/pythonw.exe`；对 60 万条已发布合成消息的档案启动另 50 万条导入，关窗选择停止后退出，任务记录为已取消，服务正常关闭。重启后 600,004 条已发布消息可读，原任务范围可重试。维护中打开另一合成会话导出面板；保存对话框期间点击主窗关闭，窗口保持，指定隔离路径保存的 ZIP 包含该会话的 TXT 和 JSON。此次大导入在范围预览期间结束，因此不将其称为“维护仍在运行时完成文件写入”。另以并发测试控制响应读取，确认保存进行时关窗受阻且文件写完后才允许退出。

并发桌面验收曾暴露阅读位置写入等待 SQLite 写锁时占有任务锁，使停止也被延迟。现在只在任务锁内固定账号和档案，SQLite 写入在锁外等待；回归测试保持 SQLite 写事务并发保存阅读位置，确认取消请求无需等待该写锁。最终基础版复测扫描 1,600,004 条合成消息时，切换会话后导出预览及原生保存对话框在任务运行中打开，任务完成后写入的 ZIP 含所选另一会话的 TXT 和 JSON。

完整语音版实际 CMD 入口打开合成档案；最终同步后的基础版和完整语音版随包运行时桌面 smoke test 与下游解释器启动均通过。基础版、完整语音版按 README 的 `--resources-only` 同步程序、静态资源和文档；发行 ZIP 未重打。当前保留复现脚本，验收时的合成数据和输出文件已不在工作区。

## 限制

合成进程测试覆盖的是受控 worker 及下游进程的停止和超时，未调用真实微信或真实在线服务；不据此推断真实微信加密 WAL 兼容性。未在干净 Windows 或发行 ZIP 中验证，也未完成真实模型转写。原生保存窗口的关闭保护在实际桌面检查；保存与维护同时进行时的进程内竞争另由隔离自动测试验证，不声称在桌面同时观察到两者完成。非常长的导入仍可能使阅读位置写入等待 SQLite 写锁并最终超时；本批移除了其对取消请求的阻塞，未改变 SQLite 写锁等待时限。
