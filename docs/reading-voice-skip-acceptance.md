# 阅读入口合并与手动跳过语音验收

日期：2026-10-29。承接前端体验改进，保留本轮开始时的工作区与暂存区改动；未提交 Git，不重打发行 ZIP。

## 当前行为与实现

- 阅读区仅有“阅读 / 分析”标签。“搜索消息”为阅读内工具开关；收起不改变查询。关键词、正文／成功转写匹配条件及命中数持续显示，日期控件持续可见。清除关键词保留日期，日下钻另行清除。切换会话沿用可见条件。
- `main.tsx` 将工具展开状态与阅读视图分开，继续使用现有完整查询、分页、命中导出和上下文位置保存；分析仍使用原组合筛选和原文回查接口。
- `archive_store.py` 新增账号档案内 `voice_skips` 表，以 username 和稳定消息 ID 保存人工标记。原语音、转写记录及失败原因保留；语音查询、阅读、分析将有效状态显示为“无需转写”。本地消息身份升级为服务器 ID 时随事务迁移标记。
- `/api/voice-skip` 校验固定账号、任务空闲、消息范围和失败状态；整批先校验再写入。成功文本不能标记覆盖；重复目标去重。恢复只删除标记，原失败原因保留。
- 语音管理支持单条、当前页及跨页选择的批量标记／恢复，增加“无需转写”筛选。失败原因按需展开；保存期间禁止修改选择，避免请求返回清空新选择；最终构建以 800 ms 延迟恢复保存实际复测，全选按钮在请求期间禁用，保存后恢复可用。手动操作后收起该面板的旧任务反馈。
- 转写预览列出范围总数、无需转写、已有成功和待处理数；已有成功依原逻辑核对媒体后复用，媒体变化仍可识别。执行在读取媒体和调用识别器前排除标记，包括明确选择的重识别和原范围重试；任务结果列出实际跳过数。全部跳过直接完成，不检查音频工具或在线配置。
- 普通导入不删除标记；变更输入保留被标记条目的失败记录。隐藏保留标记；永久清理本地档案同时清理标记。分析新增状态名称与回查，统计和匹配算法未变。

## 构建、运行资源和限制

前端 TypeScript 与 Vite 生产构建通过。基础版和完整语音版按 README 的 `--resources-only` 同步程序、静态资源、文档和清单；两版随包 `runtime/pythonw.exe app/desktop.py --smoke-test` 均打开实际 EdgeChromium 窗口并完成工具子进程调用，退出码均为 0、stderr 为空，数据目录为中文空格路径。证据分别在 `output/阅读跳过 基础版入口/state/logs/smoke-test.json` 与 `output/阅读跳过 完整语音版入口/state/logs/smoke-test.json`。静态产物为 `web/static/assets/index-q3hyMdxq.js` 与现有 `index-NxWp-JgI.css`。根目录或两版目录内的“启动微信聊天档案.cmd”使用更新后的运行资源。

首次新增测试按消息数组第一项推断其为语音，实际排序中该项为文本，已改为按稳定 ID 核对。一次自动化在保存尚未结束时选择语音被清空，已禁用保存期间的选择控件；手动标记后阅读未刷新已补齐 revision 联动，并在最终构建实际复测阅读与分析状态；另一次上下文点击目标在视窗外，浏览器自动滚动 8.67 px，改为点击视窗内目标后实测 400 → 400。分析回查的通用文本断言命中隐藏分析区与阅读区两个元素，已用阅读摘要单独核对。延迟路由脚本初次使用 CLI 不提供的 setTimeout 失败，改用 page.waitForTimeout 后完成恢复保存复测。这些失败尝试未记为通过。
